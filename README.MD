# Blog Django

Proyecto base de un blog web hecho con Django.

## Descripción
Estructura inicial del proyecto (blog_project) con una aplicación llamada posts. Todavía no tiene modelos ni vistas.

## Instalación
1. Clonar el repositorio:

        git clone ( URl del repositorio )
        cd ( Nombre del repositorio )

2. Crear y activar el entorno virtual:

        python -m venv venv
        .\venv\Scripts\Activate.ps1      (Windows PowerShell)
        source venv/bin/activate         (Linux o macOS)

3. Instalar dependencias:

        pip install -r requirements.txt

4. Levantar el servidor:

        python manage.py runserver

5. Abrir en el navegador: http://127.0.0.1:8000/

## Aplicaciones
- posts: aplicación inicial para las publicaciones del blog.
